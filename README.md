# Market Radar

AI가 한국과 미국 시장에서 이포가 볼 후보군을 먼저 압축하고, 이포가 차트 확인으로 최종 선별하는 정적 웹앱입니다.

## GitHub Pages

이 저장소는 Docker 없이 GitHub Pages로 실행할 수 있도록 구성됩니다.

- 앱 진입점: `market-radar/index.html`
- Pages workflow: `.github/workflows/market-radar-pages.yml`
- AI 후보군, 변동성 진단, 상대 비교를 한 화면에서 확인합니다.

GitHub Pages 설정을 켜기 전에도 아래 미리보기 주소로 현재 GitHub 배포본을 열 수 있습니다.

```text
https://raw.githack.com/Ryuun78/market-radar/gh-pages/index.html
```

처음 열 때 `Open the page` 버튼이 보이면 한 번 눌러 주세요.
